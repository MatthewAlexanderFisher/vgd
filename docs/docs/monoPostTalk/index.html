Monotonicity of Gaussian Process Posterior Variance

Kernel Conditions and Input Scaling

Matthew Fisher

Introduction

Gaussian Process Regression

Prior: f \sim \mathcal{GP}(m, k)

Posterior mean: \tilde m(x) = m(x) + k(x,X)[K+\lambda I]^{-1}(Y-m(X))

Posterior variance: \sigma^2(x; X) = k(x,x) - k(x,X)[K+\lambda I]^{-1}k(X,x)

Notes:

  • X is the training data, Y are the corresponding targets
  • \lambda is the noise variance
  • K = k(X,X) is the kernel matrix on the training data

Posterior Variance Under Input Scaling

Move observations toward the origin using a scale r > 0: k_r(x,y) = k(rx, ry) \qquad \text{(stationary: } k_r(x,y) = k(r(x-y))\text{)}

Posterior variance at the origin: \sigma^2(0; rX) = k(0,0) - g(r), \qquad g(r) = a(r)^\top A(r)^{-1} a(r)

A(r) = k_r(X,X) + \lambda I, \qquad a(r) = k_r(X,0)

Central question Does posterior uncertainty at the origin decrease as observations move closer?

Equivalent mathematical question: Is g(r) increasing as r \rightarrow 0?

Derivative identity Let \alpha(r) = A(r)^{-1} a(r). Then

g'(r) = 2 a'(r)^\top \alpha(r) - \alpha(r)^\top A'(r) \alpha(r)

Research problem:
Under what conditions on the kernel k does g'(r) \le 0 hold for all r > 0?

function k(x, y) {
  const dx = x[0] - y[0], dy = x[1] - y[1];
  return sigmaF2 * Math.exp(-(dx*dx + dy*dy) / (2 * ell * ell));
}

function gram(XA, XB) {
  const nA = XA.length, nB = XB.length;
  const K = Array.from({length: nA}, () => Array(nB).fill(0));
  for (let i = 0; i < nA; i++)
    for (let j = 0; j < nB; j++)
      K[i][j] = k(XA[i], XB[j]);
  return K;
}

function cholesky(A) {
  const m = A.length;
  const L = Array.from({length: m}, () => Array(m).fill(0));
  for (let i = 0; i < m; i++) {
    for (let j = 0; j <= i; j++) {
      let s = A[i][j];
      for (let p = 0; p < j; p++) s -= L[i][p] * L[j][p];
      L[i][j] = (i === j) ? Math.sqrt(Math.max(s, 1e-14)) : s / L[j][j];
    }
  }
  return L;
}

function cholSolve(A, b) {
  const L = cholesky(A), m = A.length;
  const z = Array(m).fill(0);
  for (let i = 0; i < m; i++) {
    let s = b[i];
    for (let p = 0; p < i; p++) s -= L[i][p] * z[p];
    z[i] = s / L[i][i];
  }
  const x = Array(m).fill(0);
  for (let i = m - 1; i >= 0; i--) {
    let s = z[i];
    for (let p = i + 1; p < m; p++) s -= L[p][i] * x[p];
    x[i] = s / L[i][i];
  }
  return x;
}

origin = [0, 0]
rX = X.map(([x1, x2]) => [r * x1, r * x2])

posteriorResult = {
  const Krr = gram(rX, rX);
  for (let i = 0; i < n; i++) Krr[i][i] += lambda;
  const a = rX.map(xi => k(xi, origin));
  const u = cholSolve(Krr, a);
  const g = a.reduce((acc, ai, i) => acc + ai * u[i], 0);
  return {g, sigma2: k(origin, origin) - g};
}

Background Material

Radial Gaussian Process Kernels

We focus on isotropic kernels:

k(x,y) = \varphi(\|x-y\|^2)

Examples:

  • Gaussian
  • Matérn
  • Rational quadratic

Completely Monotone Kernels

A kernel is completely monotone if

k(x,y) = \varphi(\|x-y\|^2)

where

(-1)^n \varphi^{(n)}(h) \ge 0

Examples:

  • Gaussian (yes)
  • Matérn (not always)
  • Rational quadratic (yes)

Bernstein functions generate kernels

A Bernstein function satisfies:

  • increasing
  • concave
  • f'(h) completely monotone

These generate kernels:

k(x,y) = e^{-f(\|x-y\|^2)}

This defines a valid Gaussian process kernel.

Correspondence with completely monotone kernels

There is a one-to-one correspondence:

\varphi(h) = e^{-f(h)}

Then

  • f Bernstein \iff \varphi completely monotone

Therefore Bernstein functions parameterise completely monotone kernels.

Why Bernstein structure is useful

Our (scaled) kernel has form:

k_r(x,y) = e^{-f(r^2\|x-y\|^2)}

Derivative introduces term:

h f'(h)

We need this to preserve the Bernstein property.

Thorin–Bernstein functions

A Thorin–Bernstein function (Schilling et al., 2012) is a Bernstein function which additionally satisfies:

h f'(h) \text{ is Bernstein}

This ensures

  • derivative kernel remains CND
  • monotonicity holds

Main results

Representation of k

Assume the (scaled) kernel can be written as k_r(x,y) = \exp\{-\eta_r(x,y)\}, \qquad \eta_r(x,y) = \eta(rx,ry), where \eta is conditionally negative definite (CND).

  • By Schoenberg’s criterion (Schoenberg, 1938), k_r is positive definite (PD) for all r>0 iff \eta_r is CND.

Theorem 1 (Monotonicity condition) If, for some r>0, the derivative \partial_r \eta_r(x,y) is a CND function, then g'(r) \le 0.

Proof sketch

We start from the derivative identity:

g'(r) = -2\sum_i \eta_r'(x_i,0)\,k_r(x_i,0)\,\alpha_i + \sum_{i,j} \alpha_i\alpha_j\, \eta_r'(x_i,x_j)\, k_r(x_i,x_j)

Use the CND structure

If \eta_r' is CND, then by the polarisation identity:

\eta_r'(x,y) = \eta_r'(x,0) + \eta_r'(y,0) - \psi_r(x,y)

where \psi_r is positive definite.

Use the linear system

Recall:

(K_r + \lambda I)\alpha = k_r(0,X)

This implies

\sum_j k_r(x_i,x_j)\alpha_j = k_r(x_i,0) - \lambda \alpha_i

Substitute into g'(r).

Result

After simplification:

g'(r) = -2\lambda \sum_i \alpha_i^2 \eta_r'(x_i,0) - \sum_{i,j} \alpha_i\alpha_j \psi_r(x_i,x_j) k_r(x_i,x_j)

Sign of each term

Since:

  • \eta_r' is CND ⇒ \eta_r'(x_i,0) \ge 0
  • \psi_r is PD
  • k_r is PD

both terms are non-positive

Conclusion

g'(r) \le 0

Therefore posterior variance decreases.

Main theorem

Theorem 2 (Sufficient Condtion for Monotonicity of Posterior Variance) If k(x,y) = \exp\{-f(\|x-y\|^2)\}

and f is Thorin–Bernstein, then

g'(r) \le 0

Key reason

Thorin–Bernstein \Rightarrow \eta_r' is CND \Rightarrow monotonicity

Proof sketch

Start from the representation

\eta_r(x,y) = f\!\left(r^2 \|x-y\|^2\right), \qquad f \in \mathcal{TBF}

Differentiate with respect to r:

\eta_r'(x,y) = 2r \|x-y\|^2 \, f'\!\left(r^2 \|x-y\|^2\right)

Key structural property:

If f is Thorin–Bernstein, then

u(h) = h f'(h)

is a Bernstein function

Therefore

  • u(\|x-y\|^2) is CND
  • scaling preserves the CND property

so

\eta_r' \text{ is CND}

Apply previous theorem:

\eta_r' \text{ CND} \quad \Rightarrow \quad g'(r) \le 0

Implications and counter-examples

Kernels satisfying the conditions

Recall the main result. If k(x,y) = \exp\{-f(\|x-y\|^2)\}, where f is a Thorin–Bernstein function, then g'(r) \le 0.

Examples:

  • Gaussian kernel (yes)
  • Rational quadratic kernel (yes)
  • Matérn kernel (not always)

A counterexample kernel (Bernstein but not Thorin–Bernstein)

From the Levy–Khintchine representation, take f(h)=a+bh+\int_0^\infty (1-e^{-ht})\,\mu(dt), and choose a=b=0 and \mu=\delta_1 (Dirac mass at t=1). Then f(h)=1-e^{-h} is a Bernstein function.

Therefore the kernel k(x,y)=\exp\!\Big\{-f(\|x-y\|^2)\Big\} =\exp\!\left\{-\left(1-e^{-\|x-y\|^2}\right)\right\} is completely monotone (and hence PD).

We call this the Exp–Exp kernel.

function k_ee(x, y) {
  const dx = x[0] - y[0], dy = x[1] - y[1];
  const dist2 = dx*dx + dy*dy;
  return Math.exp(-(1 - Math.exp(-dist2)));
}

  return K;
}
